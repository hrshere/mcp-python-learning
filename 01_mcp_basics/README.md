# Module 01: MCP Protocol & FastMCP Fundamentals

In this module, you will learn how to build, run, and test MCP servers in Python using FastMCP.

## Files
- `server.py`: Minimal MCP server initialization.
- `custom_tools.py`: Comprehensive example exposing:
  - **Tools**: `add_numbers`, `format_greeting`
  - **Resource**: `config://app-settings`
  - **Prompt Template**: `explain_code_prompt`

## How to Run

Activate your virtual environment and run:

```bash
source ../venv/bin/activate
python custom_tools.py
```
