# Module 02: LLM Tool Calling & MCP Integration

In this module, we will write a Python script (using Gemini API or OpenAI SDK) that acts as an **MCP Client**. It will:
1. Connect to an MCP server via stdio transport.
2. Fetch available tools automatically.
3. Pass tool definitions to the LLM.
4. Intercept function call requests from the LLM, execute the tool via MCP, and return results.
